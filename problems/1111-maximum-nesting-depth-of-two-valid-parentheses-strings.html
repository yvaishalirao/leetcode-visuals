Maximum Nesting Depth of Two Valid Parentheses Strings

View on LeetCode ↗
Split a valid parentheses string into two valid strings A (0) and B (1) so the deeper of the two is as shallow as possible. Track the nesting depth of each bracket and alternate by depth: odd levels go to one string, even levels to the other. A ( and its matching ) sit at the same depth, so they always land in the same string and both halves stay valid — and each half gets about half the levels, giving ceil(maxDepth / 2). O(n) time.
Solution code
class Solution(object):
    def maxDepthAfterSplit(self, seq):
        result = []
        depth = 0
        for ch in seq:
            if ch == '(':
                depth += 1
                result.append(depth % 2)
            else:
                result.append(depth % 2)
                depth -= 1
        return result
