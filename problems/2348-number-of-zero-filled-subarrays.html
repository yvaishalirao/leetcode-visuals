#2348

Number of Zero-Filled Subarrays

View on LeetCode ↗
Count all-zero subarrays. The trick: for a run of k consecutive zeros, arriving at the k-th zero of the run adds exactly k new zero-subarrays — every subarray ending here, of length 1 through k. So just track the current zero-streak and add it to the total at every zero.
Solution code
class Solution(object):
    def zeroFilledSubarray(self, nums):
        cnt, streak = 0, 0
        for num in nums:
            if num == 0:
                streak += 1
                cnt += streak
            else:
                streak = 0
        return cnt
