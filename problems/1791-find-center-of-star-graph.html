Find Center of Star Graph

View on LeetCode ↗
In a star graph one center node is connected to every other node, and there are no other edges. So every edge touches the center — which means any two edges share exactly one node, and that node is the center. Look at just the first two edges: whichever endpoint of edge 0 also appears in edge 1 is the answer. O(1) time and space, no matter how big the graph.
Solution code
class Solution(object):
    def findCenter(self, edges):
        a, b = edges[0]
        c, d = edges[1]
        return a if a in (c, d) else b
