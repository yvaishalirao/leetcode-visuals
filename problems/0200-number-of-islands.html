#200

Number of Islands

View on LeetCode ↗
Count groups of '1' cells connected up/down/left/right. Scan the grid; the first land cell of an unvisited island bumps the count, then a DFS sinks the whole island (turns every connected '1' into '0') so none of its cells is counted again. Each cell is sunk at most once → O(rows · cols) time.
Solution code
class Solution(object):
    def numIslands(self, grid):
        rows, cols = len(grid), len(grid[0])

        def sink(r, c):
            if 0 <= r < rows and 0 <= c < cols and grid[r][c] == '1':
                grid[r][c] = '0'
                sink(r + 1, c)
                sink(r - 1, c)
                sink(r, c + 1)
                sink(r, c - 1)

        islands = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == '1':
                    islands += 1
                    sink(r, c)
        return islands
