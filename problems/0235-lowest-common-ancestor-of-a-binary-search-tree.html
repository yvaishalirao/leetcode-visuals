Lowest Common Ancestor of a Binary Search Tree

View on LeetCode ↗
Given a BST and two node values p and q, find their lowest common ancestor. The BST property makes this a single path down the tree: if both targets are smaller than the current node, go left; if both are larger, go right; the moment they split (or one equals the current node), that node is the LCA.
Solution code
class Solution(object):
    def lowestCommonAncestor(self, root, p, q):
        if not root:
            return None

        if p.val < root.val and q.val < root.val:
            return self.lowestCommonAncestor(root.left, p, q)

        if p.val > root.val and q.val > root.val:
            return self.lowestCommonAncestor(root.right, p, q)

        return root
