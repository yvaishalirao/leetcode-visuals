Replace All ?'s to Avoid Consecutive Repeating Characters

View on LeetCode ↗
Replace every ? with a lowercase letter so no two neighbours are equal (the original letters already have no repeats). A ? only has two neighbours, so at most two letters are ruled out — one of 'a', 'b', 'c' is always free. Go left to right; the left neighbour is already final (a replaced ? counts), and the right one is either a fixed letter or another ? that will avoid us later. O(n) time.
Solution code
class Solution(object):
    def modifyString(self, s):
        chars = list(s)
        for i, ch in enumerate(chars):
            if ch == '?':
                left = chars[i - 1] if i > 0 else ''
                right = chars[i + 1] if i + 1 < len(chars) else ''
                for c in "abc":
                    if c != left and c != right:
                        chars[i] = c
                        break
        return ''.join(chars)
