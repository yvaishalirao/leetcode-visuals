Longest Substring with At Least K Repeating Characters

View on LeetCode ↗
Find the longest substring where every character appears at least k times. Divide and conquer: count the characters in s. If some character appears fewer than k times in the whole string, no valid substring can contain it — so split s around it and solve each piece separately. If no character is short, the whole string is valid. Each level of recursion removes at least one distinct letter, so the depth is at most 26 → O(26·n) time.
Solution code
from collections import Counter

class Solution(object):
    def longestSubstring(self, s, k):
        if len(s) < k:
            return 0

        count = Counter(s)
        for ch in s:
            if count[ch] < k:
                return max(self.longestSubstring(part, k) for part in s.split(ch))

        return len(s)
