Sort Integers by The Power Value

View on LeetCode ↗
The power of x is how many steps it takes to reach 1 (halve if even, 3x + 1 if odd). Sort lo..hi by (power, value) and return the k-th. Chains overlap a lot — 12 → 6 → 3 → … reuses 6's chain — so memoise: power(x) = 1 + power(next), and once any number's power is known it's never walked again. Then a single sort with the tuple key handles the tie-break.
Solution code
class Solution(object):
    def getKth(self, lo, hi, k):
        memo = {1: 0}

        def power(x):
            if x not in memo:
                memo[x] = 1 + power(x // 2 if x % 2 == 0 else 3 * x + 1)
            return memo[x]

        return sorted(range(lo, hi + 1), key=lambda x: (power(x), x))[k - 1]
