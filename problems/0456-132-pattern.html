132 Pattern

View on LeetCode ↗
Find i < j < k with nums[i] < nums[k] < nums[j]. Scan right to left with a monotonic stack. Whenever a bigger value pops smaller ones off the stack, the last popped value becomes m — the best candidate for the pattern's middle-sized "2" element. If a later (further-left) value is smaller than m, it can be the "1" — pattern found.
Solution code
class Solution(object):
    def find132pattern(self, nums):
        if len(nums) < 3:
            return False
        m = float('-inf')
        stack = []
        for i in range(len(nums)-1, -1, -1):
            if nums[i] < m:
                return True
            else:
                while stack and stack[-1] < nums[i]:
                    m = stack.pop()
            stack.append(nums[i])
        return False
nums — scanned right to left
stack — monotonic decreasing (bottom → top, left → right)
