Clone Graph

View on LeetCode ↗
Deep-copy a connected undirected graph. The trap is cycles: a naive recursive copy would loop forever and copy nodes twice. Keep a map clones from each original node to its copy. clone(n) returns the existing copy if there is one; otherwise it creates the copy, stores it in the map first, then clones each neighbour and links it. Storing before recursing is what stops the cycles. Every node and edge is handled once → O(V + E).
Solution code
class Solution(object):
    def cloneGraph(self, node):
        clones = {}

        def clone(n):
            if n in clones:
                return clones[n]
            copy = Node(n.val)
            clones[n] = copy
            for nb in n.neighbors:
                copy.neighbors.append(clone(nb))
            return copy

        return clone(node) if node else None
