Unique 3-Digit Even Numbers

View on LeetCode ↗
Count the distinct 3-digit even numbers you can build from digits, using each copy at most once and no leading zero. Instead of generating permutations (and de-duplicating), flip it around: there are only 450 even numbers from 100 to 998. For each one, check that digits has enough copies of every digit it needs. Distinctness comes for free, and the work is constant — O(450) checks no matter the input.
Solution code
from collections import Counter

class Solution(object):
    def totalNumbers(self, digits):
        have = Counter(digits)
        count = 0

        for num in range(100, 1000, 2):
            need = Counter(map(int, str(num)))
            if all(have[d] >= k for d, k in need.items()):
                count += 1

        return count
have = Counter(digits)
