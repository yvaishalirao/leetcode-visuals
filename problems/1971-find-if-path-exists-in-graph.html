Find if Path Exists in Graph

View on LeetCode ↗
Is there any path from source to destination in an undirected graph? Build an adjacency list (add each edge both ways), then BFS from source. Mark nodes as seen when they're queued so nothing is queued twice. If destination is ever popped, a path exists; if the queue runs dry first, it doesn't. O(V + E) time and space.
Solution code
from collections import deque

class Solution(object):
    def validPath(self, n, edges, source, destination):
        graph = [[] for _ in range(n)]
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        seen = {source}
        queue = deque([source])
        while queue:
            node = queue.popleft()
            if node == destination:
                return True
            for nxt in graph[node]:
                if nxt not in seen:
                    seen.add(nxt)
                    queue.append(nxt)

        return False
