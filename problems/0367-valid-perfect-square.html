Valid Perfect Square

View on LeetCode ↗
Return true if num is a perfect square, without using sqrt. The trick: k² = 1 + 3 + 5 + … + (2k−1) — the sum of the first k odd numbers. So repeatedly subtract consecutive odd numbers; landing exactly on 0 means num was a perfect square.
Solution code
class Solution(object):
    def isPerfectSquare(self, num):
        i = 1
        while (num>0):
            num -= i
            i += 2
        return num == 0
