Delete and Earn

View on LeetCode ↗
Picking x earns x points but deletes every x-1 and x+1. If you take one x you may as well take all of them, so first total up points[x] = x × count(x). Now taking value x forbids its neighbours x-1 and x+1 — this is exactly House Robber on the points array. Walk the values keeping two numbers: take (best if we take this value) and skip (best if we don't). O(n + max) time, O(max) space.
Solution code
class Solution(object):
    def deleteAndEarn(self, nums):
        points = [0] * (max(nums) + 1)
        for x in nums:
            points[x] += x

        take, skip = 0, 0
        for p in points:
            take, skip = skip + p, max(take, skip)

        return max(take, skip)
