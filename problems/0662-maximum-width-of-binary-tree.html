#662

Maximum Width of Binary Tree

View on LeetCode ↗
Return the maximum width among all levels, where width counts the null gaps between the leftmost and rightmost real nodes as if the tree were complete. The trick: give the root position 1, and every node at position pos gives its left child position 2·pos and right child 2·pos+1 — exactly like array-indexing a complete binary tree. A level's width is then just last.pos − first.pos + 1.
Solution code
class Solution(object):
    def widthOfBinaryTree(self, root):
        if not root: return 0
        q = [(root, 1)]
        ans = 1
        while q:
            if len(q) >= 2:
                ans = max(q[-1][1] - q[0][1] + 1, ans)
            new_q = []
            while q:
                node, pos = q.pop(0)
                if node.left: new_q.append((node.left, 2*pos))
                if node.right: new_q.append((node.right, 2*pos + 1))
            q = new_q
        return ans
