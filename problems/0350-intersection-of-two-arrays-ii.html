Intersection of Two Arrays II

View on LeetCode ↗
Return the common elements, each appearing as many times as it shows up in both arrays. Count nums1 with a hash map. Walk nums2: if the current value still has a count left, it's a match — append it and use up one copy. Values run out exactly when nums1 has no more copies to pair with. O(n + m) time, O(n) space.
Solution code
from collections import Counter

class Solution(object):
    def intersect(self, nums1, nums2):
        count = Counter(nums1)
        result = []
        for x in nums2:
            if count[x] > 0:
                result.append(x)
                count[x] -= 1
        return result
