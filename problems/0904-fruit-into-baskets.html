#904

Fruit Into Baskets

View on LeetCode ↗
Two baskets, each holding one fruit type; pick from consecutive trees and stop at a third type. That's the longest subarray with at most 2 distinct values. Sliding window: add fruits[right] to a count map; while the map has more than 2 types, drop fruits[left] and move left right (deleting a type when its count hits 0). Each tree enters and leaves the window once → O(n) time, O(1) space.
Solution code
class Solution(object):
    def totalFruit(self, fruits):
        count = {}
        left = best = 0
        for right, f in enumerate(fruits):
            count[f] = count.get(f, 0) + 1
            while len(count) > 2:
                count[fruits[left]] -= 1
                if count[fruits[left]] == 0:
                    del count[fruits[left]]
                left += 1
            best = max(best, right - left + 1)
        return best
