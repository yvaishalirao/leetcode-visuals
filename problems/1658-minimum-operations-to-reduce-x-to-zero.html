#1658

Minimum Operations to Reduce X to Zero

View on LeetCode ↗
Each operation removes the leftmost or rightmost number and subtracts it from x. Whatever we remove is a prefix plus a suffix, so what stays is one contiguous middle block summing to sum(nums) − x. Fewest removals = longest middle block with that sum. All numbers are positive, so a sliding window works: grow on the right, shrink from the left while the window is too big. O(n) time, O(1) space.
Solution code
class Solution(object):
    def minOperations(self, nums, x):
        target = sum(nums) - x
        if target < 0:
            return -1

        best = -1
        window = left = 0
        for right, num in enumerate(nums):
            window += num
            while window > target:
                window -= nums[left]
                left += 1
            if window == target:
                best = max(best, right - left + 1)

        return len(nums) - best if best != -1 else -1
