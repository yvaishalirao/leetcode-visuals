#889

Construct Binary Tree from Preorder and Postorder Traversal

View on LeetCode ↗
Unlike the recursive split approach, this solution walks preorder left to right while keeping a stack of the current root-to-node path. Each new preorder value attaches as the top-of-stack's left child (if empty) or right child, then gets pushed itself. A pointer into postorder detects when the stack's top node has no more children coming — its value will equal postorder[j] — and pops it off.
Solution code
class Solution(object):
    def constructFromPrePost(self, pre, post):
        stack = [TreeNode(pre[0])]
        j = 0
        for v in pre[1:]:
            node = TreeNode(v)
            while stack[-1].val == post[j]:
                stack.pop()
                j += 1
            if not stack[-1].left:
                stack[-1].left = node
            else:
                stack[-1].right = node
            stack.append(node)
        return stack[0]
preorder — current value
postorder — j marks the completion pointer
stack — root-to-current-node path
