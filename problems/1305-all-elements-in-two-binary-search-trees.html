All Elements in Two Binary Search Trees

View on LeetCode ↗
Given two binary search trees, return a list of all their values, sorted ascending. No need for a merge-like approach here — just collect every value from both trees (any traversal order works) and sort once at the end.
Solution code
class Solution(object):
    def getAllElements(self, root1, root2):
        ans = []

        def trav(root):
            if root is None:
                return
            ans.append(root.val)
            trav(root.left)
            trav(root.right)

        trav(root1)
        trav(root2)

        ans.sort()
        return ans
