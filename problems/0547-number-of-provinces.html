#547

Number of Provinces

View on LeetCode ↗
A province is a group of cities connected directly or through other cities — a connected component. Walk the cities in order; each one not yet seen starts a new province, and a DFS from it marks every city reachable through isConnected. The number of DFS starts is the answer. The matrix is n × n, so O(n²) time, O(n) space.
Solution code
class Solution(object):
    def findCircleNum(self, isConnected):
        n = len(isConnected)
        seen = [False] * n

        def dfs(city):
            for nxt in range(n):
                if isConnected[city][nxt] and not seen[nxt]:
                    seen[nxt] = True
                    dfs(nxt)

        provinces = 0
        for city in range(n):
            if not seen[city]:
                seen[city] = True
                dfs(city)
                provinces += 1
        return provinces
