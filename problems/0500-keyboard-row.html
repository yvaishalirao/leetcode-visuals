Keyboard Row

View on LeetCode ↗
Return the words that can be typed using letters from only one row of an American keyboard. Build a lookup row_of[letter] once. For each word, the first letter fixes the target row — then every other letter must map to that same row. all() stops at the first letter on a different row. O(total letters) time, O(1) extra space (26-entry map).
Solution code
class Solution(object):
    def findWords(self, words):
        rows = ["qwertyuiop", "asdfghjkl", "zxcvbnm"]
        row_of = {}
        for r, keys in enumerate(rows):
            for ch in keys:
                row_of[ch] = r

        result = []
        for word in words:
            w = word.lower()
            target = row_of[w[0]]
            if all(row_of[ch] == target for ch in w):
                result.append(word)

        return result
