Max Increase to Keep City Skyline

View on LeetCode ↗
Raise buildings as much as possible without changing the skyline seen from any side. The skyline from the left/right is each row's max; from the top/bottom it's each column's max. Building (i, j) can rise to min(row_max[i], col_max[j]) — any taller and it would poke above one of the two skylines. Sum those gains. O(n²) time, O(n) space.
Solution code
class Solution(object):
    def maxIncreaseKeepingSkyline(self, grid):
        row_max = [max(row) for row in grid]
        col_max = [max(col) for col in zip(*grid)]

        total = 0
        for i, row in enumerate(grid):
            for j, h in enumerate(row):
                total += min(row_max[i], col_max[j]) - h

        return total
grid — row_max on the right, col_max along the bottom
