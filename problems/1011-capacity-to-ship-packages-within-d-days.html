Capacity To Ship Packages Within D Days

View on LeetCode ↗
Packages ship in order; find the smallest ship capacity that gets them all out within days. For a given capacity, a greedy pass tells us how many days it takes (load each day until the next package won't fit). Bigger capacity never needs more days, so binary search the answer between max(weights) (must fit the heaviest package) and sum(weights) (everything in one day). O(n log(sum)) time.
Solution code
class Solution(object):
    def shipWithinDays(self, weights, days):
        def days_needed(cap):
            need, load = 1, 0
            for w in weights:
                if load + w > cap:
                    need += 1
                    load = 0
                load += w
            return need

        lo, hi = max(weights), sum(weights)
        while lo < hi:
            mid = (lo + hi) // 2
            if days_needed(mid) <= days:
                hi = mid
            else:
                lo = mid + 1

        return lo
