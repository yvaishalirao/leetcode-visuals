#678

Valid Parenthesis String

View on LeetCode ↗
Each * can be (, ) or nothing. Instead of trying every choice, track the range of possible open-bracket counts: lo (fewest open) and hi (most open). ( raises both, ) lowers both, * lowers lo and raises hi. If hi drops below 0, even the most generous choices have too many ) → invalid. lo can't go below 0 (we'd just not use a * as )), so clamp it. Valid if 0 is possible at the end: lo == 0. O(n) time, O(1) space.
Solution code
class Solution(object):
    def checkValidString(self, s):
        lo = hi = 0
        for ch in s:
            if ch == '(':
                lo += 1
                hi += 1
            elif ch == ')':
                lo -= 1
                hi -= 1
            else:
                lo -= 1
                hi += 1
            if hi < 0:
                return False
            lo = max(lo, 0)
        return lo == 0
