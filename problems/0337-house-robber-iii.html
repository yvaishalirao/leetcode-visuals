House Robber III

View on LeetCode ↗
Houses form a binary tree; two directly-linked houses can't both be robbed. Return the maximum amount robbable. Each node's postorder call returns a pair [rob, skip] — the best total if this node is robbed, and the best total if it isn't — computed from its children's pairs.
Solution code
class Solution(object):
    def rob(self, root):
        def travel(root):
            if root is None:
                return [0,0]
            ln=travel(root.left)
            rn=travel(root.right)
            ans=[0,0]
            ans[0]=root.val+ln[1]+rn[1]
            ans[1]=max(ln[0],ln[1])+max(rn[0],rn[1])
            return ans

        ans=travel(root)
        return max(ans[0],ans[1])
