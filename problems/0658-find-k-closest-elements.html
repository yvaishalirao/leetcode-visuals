Find K Closest Elements

View on LeetCode ↗
Return the k elements of sorted arr closest to x (ties prefer the smaller value). The answer is always a contiguous window arr[left : left + k], so binary search for left in [0, n − k]. For a candidate mid, compare the window's first element arr[mid] with the element just past it, arr[mid + k]: if x − arr[mid] > arr[mid + k] − x, the right one is strictly closer, so the window must slide right; otherwise it starts at mid or earlier. O(log(n − k) + k) time.
Solution code
class Solution(object):
    def findClosestElements(self, arr, k, x):
        lo, hi = 0, len(arr) - k
        while lo < hi:
            mid = (lo + hi) // 2
            if x - arr[mid] > arr[mid + k] - x:
                lo = mid + 1
            else:
                hi = mid
        return arr[lo:lo + k]
