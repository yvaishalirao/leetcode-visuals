Monotone Increasing Digits

View on LeetCode ↗
Return the largest number ≤ N whose digits never decrease left to right. This solution works on the reversed digit array (so num[0] is the units digit) and tracks inv_index — the leftmost position (in the original number) where the monotone property breaks, including cascades where equal neighboring digits push the break further left.
Solution code
class Solution(object):
    def monotoneIncreasingDigits(self, N):
        if N < 10: return N
        n, inv_index = N, -1
        num = [int(d) for d in str(n)[::-1]]

        for i in range(1, len(num)):
            if num[i] > num[i - 1] or (inv_index != -1 and num[inv_index] == num[i]):
                inv_index = i

        if inv_index == -1: return N

        for i in range(inv_index): num[i] = 9
        num[inv_index] -= 1

        return int(''.join([ str(i) for i in num[::-1]]))
