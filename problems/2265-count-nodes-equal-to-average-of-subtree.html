#2265

Count Nodes Equal to Average of Subtree

View on LeetCode ↗
Count nodes whose value equals the (floored) average of their own subtree. A subtree's average needs its sum and its node count — and both can be built from the children's. So do one post-order DFS that returns (sum, count): combine the left and right results with the node itself, test sum // count == node.val, and pass the pair up. Every node is visited once → O(n) time, O(h) stack.
Solution code
class Solution(object):
    def averageOfSubtree(self, root):
        self.count = 0

        def dfs(node):
            if not node:
                return 0, 0
            left_sum, left_cnt = dfs(node.left)
            right_sum, right_cnt = dfs(node.right)
            total = left_sum + right_sum + node.val
            cnt = left_cnt + right_cnt + 1
            if total // cnt == node.val:
                self.count += 1
            return total, cnt

        dfs(root)
        return self.count
