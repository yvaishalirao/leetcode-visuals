Longest Palindrome

View on LeetCode ↗
Return the length of the longest palindrome you can build from the letters of s (case-sensitive). A palindrome is mirrored pairs around an optional single middle letter. So from each letter's count, use as many pairs as possible: count // 2 * 2. If any letter has a leftover (an odd count), one of them can sit in the middle for +1. O(n) time.
Solution code
from collections import Counter

class Solution(object):
    def longestPalindrome(self, s):
        length = 0
        has_odd = False
        for c in Counter(s).values():
            length += c // 2 * 2
            if c % 2:
                has_odd = True
        return length + 1 if has_odd else length
