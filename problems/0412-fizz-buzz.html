Fizz Buzz

View on LeetCode ↗
For each i from 1 to n: multiples of 3 become "Fizz", multiples of 5 become "Buzz", multiples of both become "FizzBuzz", and everything else stays as the number. Build the word by appending — "Fizz" if divisible by 3, then "Buzz" if divisible by 5 — so the FizzBuzz case needs no separate check. If the word is still empty, use the number. O(n) time.
Solution code
class Solution(object):
    def fizzBuzz(self, n):
        result = []
        for i in range(1, n + 1):
            word = ""
            if i % 3 == 0:
                word += "Fizz"
            if i % 5 == 0:
                word += "Buzz"
            result.append(word or str(i))
        return result
