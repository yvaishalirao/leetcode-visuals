Invert Binary Tree

View on LeetCode ↗
Given the root of a binary tree, invert the tree (mirror it left-right) and return its root. The recursion inverts both subtrees first, then swaps the current node's own left and right pointers — so the tree's layout actually flips as you step through.
Solution code
class Solution(object):
    def invertTree(self, root):
        if not root:
            return root
        self.invertTree(root.left)
        self.invertTree(root.right)
        root.left, root.right = root.right, root.left
        return root
