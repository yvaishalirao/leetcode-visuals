Array Partition

View on LeetCode ↗
Split 2n numbers into n pairs to maximise the sum of each pair's minimum. The smallest number is always some pair's minimum, so pair it with the second smallest — wasting anything bigger on it would throw that value away. Repeat: after sorting, pair neighbours (0,1), (2,3), … and the minimum of each pair is the element at the even index. O(n log n) time.
Solution code
class Solution(object):
    def arrayPairSum(self, nums):
        nums.sort()
        return sum(nums[::2])
