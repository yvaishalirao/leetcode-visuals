#611

Valid Triangle Number

View on LeetCode ↗
Count triplets that can be triangle sides. With sides sorted a ≤ b ≤ c, the only check needed is a + b > c. Sort, then fix the largest side c from the right and run two pointers lo, hi on the values before it. If nums[lo] + nums[hi] > nums[c], then every index from lo to hi−1 also works with hi (they're even bigger) → add hi − lo at once and move hi left. Otherwise nums[lo] is too small → move lo right. O(n²) time.
Solution code
class Solution(object):
    def triangleNumber(self, nums):
        nums.sort()
        count = 0

        for c in range(len(nums) - 1, 1, -1):
            lo, hi = 0, c - 1
            while lo < hi:
                if nums[lo] + nums[hi] > nums[c]:
                    count += hi - lo
                    hi -= 1
                else:
                    lo += 1

        return count
