Find Numbers with Even Number of Digits

View on LeetCode ↗
Given an array of integers, count how many have an even number of digits — just convert each to a string and check its length.
Solution code
class Solution(object):
    def findNumbers(self, nums):
        count = 0
        for i in nums:
            s = str(i)
            if len(s) % 2 == 0:
                count += 1
        return count
