Non-overlapping Intervals

View on LeetCode ↗
Remove the fewest intervals so the rest don't overlap (touching at an endpoint is fine). Flip it: keep as many as possible. Sort by end time and greedily keep each interval that starts at or after the last kept end — the interval that finishes earliest leaves the most room for everything after it. Anything that starts before prev_end overlaps and is removed. O(n log n) time.
Solution code
class Solution(object):
    def eraseOverlapIntervals(self, intervals):
        intervals.sort(key=lambda iv: iv[1])
        removed = 0
        prev_end = float('-inf')

        for start, end in intervals:
            if start >= prev_end:
                prev_end = end
            else:
                removed += 1

        return removed
