Find the Town Judge

View on LeetCode ↗
The judge trusts nobody and is trusted by everyone else. Give each person a single score = (people who trust them) − (people they trust). Every trust pair [a, b] does score[a] -= 1, score[b] += 1. Only the judge can reach n − 1: that needs all n − 1 others trusting them and zero outgoing trust. O(n + trust) time, O(n) space.
Solution code
class Solution(object):
    def findJudge(self, n, trust):
        score = [0] * (n + 1)
        for a, b in trust:
            score[a] -= 1
            score[b] += 1

        for person in range(1, n + 1):
            if score[person] == n - 1:
                return person
        return -1
