Minimum Add to Make Parentheses Valid

View on LeetCode ↗
Fewest parentheses to insert so the string is valid. No stack needed — just two counters. open_count = ( still waiting for a match. A ) uses one up if there is one; if not, it can never be matched by anything later, so we must insert a ( for it (add += 1). At the end, every still-open ( needs a ) too. O(n) time, O(1) space.
Solution code
class Solution(object):
    def minAddToMakeValid(self, s):
        open_count = 0
        add = 0
        for ch in s:
            if ch == '(':
                open_count += 1
            elif open_count:
                open_count -= 1
            else:
                add += 1
        return add + open_count
