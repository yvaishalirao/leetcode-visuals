Perfect Number

View on LeetCode ↗
A perfect number equals the sum of its positive divisors, excluding itself (e.g. 28 = 1+2+4+7+14). Only test divisors up to √num — each one i found pairs with num // i, so both get added at once (unless i is the exact square root, to avoid double-counting).
Solution code
class Solution(object):
    def checkPerfectNumber(self, num):
        if num < 2: return False
        s = 1
        i = 2
        while i * i <= num:
            if num % i == 0:
                s += i
                if i * i != num:
                    s += num // i
            i += 1
        return s == num
