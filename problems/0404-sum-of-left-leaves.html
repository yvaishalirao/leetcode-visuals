Sum of Left Leaves

View on LeetCode ↗
Sum every leaf that is a left child. The check happens at the parent: if node.left exists and is itself a leaf, add its value directly; otherwise recurse into it. The right side is always recursed into unconditionally — right children are never summed themselves, only searched for left leaves inside them.
Solution code
class Solution:
    def sumOfLeftLeaves(self, root):
        if root is None:
            return 0

        ans = 0

        if root.left is not None:
            if root.left.left is None and root.left.right is None:
                ans += root.left.val
            else:
                ans += self.sumOfLeftLeaves(root.left)

        ans += self.sumOfLeftLeaves(root.right)

        return ans
