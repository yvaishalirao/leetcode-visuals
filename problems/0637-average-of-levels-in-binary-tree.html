Average of Levels in Binary Tree

View on LeetCode ↗
Given the root of a binary tree, return the average value of the nodes on each level. Input uses LeetCode's array form, e.g. 3,9,20,null,null,15,7.
Solution code
class Solution(object):
    def averageOfLevels(self, root):
        from collections import deque
        if root is None:
            return 0
        q=deque()
        q.append(root)
        ans=[]
        while q:
            n=len(q)
            temp=[]
            for i in range(n):
                node=q.popleft()
                if node.right is not None:
                    q.append(node.right)
                if node.left is not None:
                    q.append(node.left)
                temp.append(float(node.val))
            ans.append(float(sum(temp)/len(temp)))
        return ans
