Spiral Matrix II

View on LeetCode ↗
Fill an n×n matrix with 1..n² in spiral order. Rather than tracking explicit boundaries, this solution just walks in the current direction and turns right the moment the next cell (wrapping with %n) is already filled.
Solution code
class Solution(object):
    def generateMatrix(self, n):
        A = [[0] * n for _ in range(n)]
        i, j, di, dj = 0, 0, 0, 1
        for k in xrange(n*n):
            A[i][j] = k + 1
            if A[(i+di)%n][(j+dj)%n]:
                di, dj = dj, -di
            i += di
            j += dj
        return A
