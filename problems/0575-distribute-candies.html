Distribute Candies

View on LeetCode ↗
Alice has n candies (n is even) but may eat only n / 2. Return the most different types she can eat. Two limits apply at once: she can't eat more types than exist (len(set(candyType))), and she can't eat more than n / 2 candies total. The answer is the smaller of the two. O(n) time, O(n) space.
Solution code
class Solution(object):
    def distributeCandies(self, candyType):
        return min(len(set(candyType)), len(candyType) // 2)
