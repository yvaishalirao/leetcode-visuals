Maximum Product of Three Numbers

View on LeetCode ↗
Find three numbers whose product is maximum. Two candidates matter: the three largest values, or the largest value times the two smallest (which could both be very negative, making their product very positive). This solution avoids a full sort — a partial selection sort moves just the 2 smallest to the front and the 3 largest to the back.
Solution code
class Solution(object):
    def maximumProduct(self, A):
        n = len(A)

        for i in range(2):
            k = i
            for j in range(i + 1, n):
                if A[j] < A[k]:
                    k = j
            A[i], A[k] = A[k], A[i]

        for i in range(n - 1, max(-1, n - 4), -1):
            k = i
            for j in range(i):
                if A[j] > A[k]:
                    k = j
            A[i], A[k] = A[k], A[i]

        return max(
            A[-1] * A[-2] * A[-3],
            A[-1] * A[0] * A[1]
        )
