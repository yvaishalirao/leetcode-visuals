Most Common Word

View on LeetCode ↗
Return the most frequent word in paragraph that isn't in banned (case-insensitive, punctuation ignored). Lowercase the text and pull out the words with the regex \w+ — this drops punctuation in one step. Count every word that isn't banned (a set makes the banned check O(1)), then take the top count. O(n) time.
Solution code
import re
from collections import Counter

class Solution(object):
    def mostCommonWord(self, paragraph, banned):
        banned = set(banned)
        words = re.findall(r"\w+", paragraph.lower())
        count = Counter(w for w in words if w not in banned)
        return count.most_common(1)[0][0]
