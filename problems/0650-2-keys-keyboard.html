Starting from one 'A', using only Copy-All and Paste, find the minimum operations to reach exactly n copies. The insight: growing from k to k·p copies (p prime) always costs exactly p operations (1 copy + (p−1) pastes) — so the answer is just the sum of n's prime factors, found by repeated division.
Solution code
class Solution(object):
    def minSteps(self, n):
        if n == 1:
            return 0

        steps = 0
        factor = 2

        while n > 1:
            while n % factor == 0:
                steps += factor
                n //= factor
            factor += 1

        return steps
