#450

Delete Node in a BST

View on LeetCode ↗
Given a BST and a key, delete the node with that value and return the (possibly new) root. A node with 0–1 children is simply bypassed. A node with two children is replaced by its in-order successor — the leftmost node in its right subtree — whose value is copied in, then that successor is deleted from the right subtree.
Solution code
class Solution(object):
    def deleteNode(self, root, key):
        if not root: return None

        if root.val == key:
            if not root.right: return root.left

            if not root.left: return root.right

            if root.left and root.right:
                temp = root.right
                while temp.left: temp = temp.left
                root.val = temp.val
                root.right = self.deleteNode(root.right, root.val)

        elif root.val > key:
            root.left = self.deleteNode(root.left, key)
        else:
            root.right = self.deleteNode(root.right, key)

        return root
