#733

Flood Fill

View on LeetCode ↗
Starting at (sr, sc), repaint every cell connected to it (up/down/left/right) that has the same original colour. DFS: if a cell is in bounds and still the original colour, paint it and recurse into its four neighbours. Painting before recursing doubles as the "visited" mark. One edge case: if the new colour equals the old one, return immediately — otherwise the DFS would never see a cell as painted and loop forever. O(rows · cols) time.
Solution code
class Solution(object):
    def floodFill(self, image, sr, sc, color):
        old = image[sr][sc]
        if old == color:
            return image

        def fill(r, c):
            if 0 <= r < len(image) and 0 <= c < len(image[0]) and image[r][c] == old:
                image[r][c] = color
                fill(r + 1, c)
                fill(r - 1, c)
                fill(r, c + 1)
                fill(r, c - 1)

        fill(sr, sc)
        return image
