Minimum Time Difference

View on LeetCode ↗
Given 24-hour "HH:MM" times, return the smallest gap in minutes between any two. Convert each time to minutes since midnight and sort. After sorting, the closest pair must be neighbours — except across midnight, so also check the wrap-around gap from the last time to the first: 1440 + first − last. O(n log n) time.
Solution code
class Solution(object):
    def findMinDifference(self, timePoints):
        minutes = sorted(int(t[:2]) * 60 + int(t[3:]) for t in timePoints)

        best = 1440 + minutes[0] - minutes[-1]
        for i in range(1, len(minutes)):
            best = min(best, minutes[i] - minutes[i - 1])

        return best
