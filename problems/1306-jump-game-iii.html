Jump Game III

View on LeetCode ↗
Starting at index start, from index i you may jump to i + arr[i] or i - arr[i] (never outside the array). Return true if you can reach any index holding value 0. The trick: negate A[i] the moment it's visited — a negative value doubles as both "already explored" (skip it) and, algebraically, still yields the correct two jump targets.
Solution code
class Solution(object):
    def canReach(self, A, i):
        if 0 <= i < len(A) and A[i] >= 0:
            A[i] = -A[i]
            return A[i] == 0 or self.canReach(A, i + A[i]) or self.canReach(A, i - A[i])
        return False
arr — negated once visited (also doubles as the "already explored" marker)
