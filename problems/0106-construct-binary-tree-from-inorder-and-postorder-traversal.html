Construct Binary Tree from Inorder and Postorder Traversal

View on LeetCode ↗
Given inorder and postorder traversals of a binary tree, construct and return the tree. Each call pops the last value off postorder as the root (postorder always ends with the root), finds it in inorder to split into left/right ranges, then builds the right subtree before the left — because working backward through postorder, the tail belongs to the right subtree first.
Solution code
class Solution(object):
    def buildTree(self, inorder, postorder):
        if not inorder:
            return None

        root_val = postorder.pop()
        root = TreeNode(root_val)

        inorder_index = inorder.index(root_val)

        root.right = self.buildTree(inorder[inorder_index+1:], postorder)
        root.left = self.buildTree(inorder[:inorder_index], postorder)

        return root

inorder — current [start, end] range and split point
