#950

Reveal Cards In Increasing Order

View on LeetCode ↗
Order the deck so that repeatedly reveal the top card, then move the next card to the bottom reveals cards in increasing order. Instead of guessing the order, simulate the process on positions: a queue holds deck positions 0..n-1. The first position popped is where the smallest card must go; then the next position moves to the back, exactly like the real deck. Keep placing the next smallest card at each popped position. O(n log n) for the sort, O(n) for the simulation.
Solution code
from collections import deque

class Solution(object):
    def deckRevealedIncreasing(self, deck):
        n = len(deck)
        positions = deque(range(n))
        result = [0] * n

        for card in sorted(deck):
            result[positions.popleft()] = card
            if positions:
                positions.append(positions.popleft())

        return result
