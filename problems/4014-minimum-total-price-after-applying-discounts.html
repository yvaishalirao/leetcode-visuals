#4014

Minimum Total Price After Applying Discounts

View on LeetCode ↗
Each discount (a percentage) can go on at most one item and each item takes at most one discount. Putting d% on price p saves p × d / 100, and every saving is positive, so use as many discounts as possible. To maximise the total saving, pair the biggest discount with the biggest price, the second biggest with the second biggest, and so on — swapping any two pairs can only save less. Sort both lists in descending order and zip them. O(n log n + m log m) time.
Solution code
class Solution(object):
    def minPrice(self, prices, discounts):
        prices = sorted(prices, reverse=True)
        discounts = sorted(discounts, reverse=True)

        total = float(sum(prices))
        for p, d in zip(prices, discounts):
            total -= p * d / 100.0

        return total
