Product of the Last K Numbers

View on LeetCode ↗
Design a stream that supports add(num) and getProduct(k) (product of the last k numbers). Keep prefix products starting from [1], so the last k numbers multiply to prefix[-1] // prefix[-k-1]. A 0 would break division, so on add(0) reset to [1] — and if k reaches back past that reset, the product must include the 0, so return 0. Both operations are O(1).
Solution code
class ProductOfNumbers(object):
    def __init__(self):
        self.prefix = [1]

    def add(self, num):
        if num == 0:
            self.prefix = [1]
        else:
            self.prefix.append(self.prefix[-1] * num)

    def getProduct(self, k):
        if k >= len(self.prefix):
            return 0
        return self.prefix[-1] // self.prefix[-k - 1]
