Generate Parentheses

View on LeetCode ↗
List every valid string of n pairs of parentheses. Backtracking that only ever builds valid prefixes: add ( while fewer than n are open, and add ) only if it closes something (closed < opened). Because no invalid prefix is ever created, every string that reaches length 2n is a valid answer — nothing is generated and thrown away. Time is proportional to the output (the n-th Catalan number of strings).
Solution code
class Solution(object):
    def generateParenthesis(self, n):
        result = []

        def build(cur, opened, closed):
            if len(cur) == 2 * n:
                result.append(cur)
                return
            if opened < n:
                build(cur + '(', opened + 1, closed)
            if closed < opened:
                build(cur + ')', opened, closed + 1)

        build('', 0, 0)
        return result
