#523

Continuous Subarray Sum

View on LeetCode ↗
Given nums and k, return true if some subarray of length ≥ 2 sums to a multiple of k. Trick: if two prefix sums share the same remainder mod k, the subarray between them sums to a multiple of k — so track the first index each remainder was seen at, and check the gap.
Solution code
class Solution(object):
    def checkSubarraySum(self, nums, k):
        if not nums:
            return False

        prefix_sum = 0
        remainder_map = {0: -1}

        for i, num in enumerate(nums):
            prefix_sum += num
            remainder = prefix_sum % k

            if remainder in remainder_map:
                if i - remainder_map[remainder] > 1:
                    return True
            else:
                remainder_map[remainder] = i

        return False

remainder_map — first index each remainder was seen at
