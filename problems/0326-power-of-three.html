Power of Three

View on LeetCode ↗
Given an integer n, return true if it is a power of three (n == 3^x for some integer x ≥ 0). Repeatedly divide out factors of 3; if you're left with exactly 1, every factor was a 3.
Solution code
class Solution(object):
    def isPowerOfThree(self, n):
        if n <= 0:
            return False
        while n % 3 == 0:
            n //= 3
        return n == 1
