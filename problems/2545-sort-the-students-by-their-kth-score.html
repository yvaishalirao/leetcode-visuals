Sort the Students by Their Kth Score

View on LeetCode ↗
Each row of score is one student; column k is one exam. Reorder the rows so the student with the highest score in exam k comes first. Sort whole rows using row[k] as the key, largest first — the other columns just travel along with their row. O(m log m) time for m students.
Solution code
class Solution(object):
    def sortTheStudents(self, score, k):
        return sorted(score, key=lambda row: row[k], reverse=True)
