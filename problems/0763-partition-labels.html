Partition Labels

View on LeetCode ↗
Split s into the most parts possible so each letter appears in only one part. First record every letter's last occurrence. Then greedily grow the current window's end to the last occurrence of every letter seen so far — the moment the scan pointer i catches up to end, no letter inside can appear later, so it's safe to cut.
Solution code
class Solution(object):
    def partitionLabels(self, s):
        last_occurrence = {}

        for i, char in enumerate(s):
            last_occurrence[char] = i

        result = []
        start = 0
        end = 0

        for i, char in enumerate(s):
            end = max(end, last_occurrence[char])

            if i == end:
                result.append(end - start + 1)
                start = i + 1

        return result
