Check Completeness of a Binary Tree

View on LeetCode ↗
A complete binary tree has every level full except possibly the last, which fills left to right with no gaps. The trick: build a flat BFS array including None placeholders for missing children, but only keep expanding while the current slot is truthy. The moment a None is hit, stop — then check that nothing real appears anywhere after it.
Solution code
class Solution(object):
    def isCompleteTree(self, root):
        bfs = [root]
        i = 0
        while bfs[i]:
            bfs.append(bfs[i].left)
            bfs.append(bfs[i].right)
            i += 1
        return not any(bfs[i:])
