#3550

Smallest Index With Digit Sum Equal to Index

View on LeetCode ↗
Return the smallest index i where the digit sum of nums[i] equals i, or -1. Scan left to right — the first match is automatically the smallest, so return immediately. Digit sum: repeatedly add num % 10 (last digit) and drop it with num //= 10. O(n · digits) time, O(1) space.
Solution code
class Solution(object):
    def smallestIndex(self, nums):
        for i, num in enumerate(nums):
            digit_sum = 0
            while num:
                digit_sum += num % 10
                num //= 10
            if digit_sum == i:
                return i
        return -1
