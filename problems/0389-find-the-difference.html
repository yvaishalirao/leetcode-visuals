Find the Difference

View on LeetCode ↗
t is s shuffled with one extra letter added. Find that letter. XOR trick: x ^ x = 0 and x ^ 0 = x, and order doesn't matter. XOR the character codes of every letter in s + t — each letter that appears in both strings cancels itself out, leaving only the extra one. O(n) time, O(1) space.
Solution code
class Solution(object):
    def findTheDifference(self, s, t):
        diff = 0
        for ch in s + t:
            diff ^= ord(ch)
        return chr(diff)
