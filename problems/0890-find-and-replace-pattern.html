#890

Find and Replace Pattern

View on LeetCode ↗
Return the words that match pattern through a one-to-one letter mapping. Walk the word and pattern together with two maps: w_to_p (word letter → pattern letter) and p_to_w (the reverse). setdefault records a mapping the first time a letter appears; if a letter is ever paired with something different from what's stored, the mapping breaks. Both directions are needed — w_to_p alone would let two word letters map to the same pattern letter. O(total letters) time.
Solution code
class Solution(object):
    def findAndReplacePattern(self, words, pattern):
        def matches(word):
            w_to_p, p_to_w = {}, {}
            for w, p in zip(word, pattern):
                if w_to_p.setdefault(w, p) != p or p_to_w.setdefault(p, w) != w:
                    return False
            return True

        return [w for w in words if matches(w)]
